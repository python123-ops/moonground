# 指定米制方向的速度证据

普通“本帧测量”下方的折叠区域消费已经计算的普通测量帧，不新增观测流或检查点。先运行普通测量，再填写方向配置，点击“计算方向速度证据”。结果跟随原普通测量滑块；“下载整批方向速度证据”保存全部帧，格式为 `velocity_evidence_frame`，范围为 `model_velocity_component_band`。

```json
{
  "session_id": "warehouse-example",
  "probes": [
    {
      "probe_id": "forward",
      "direction": [1, 0],
      "threshold_mps": 1,
      "sigma_multiplier": 2
    }
  ],
  "max_tracks": 1000
}
```

方向由核心归一化一次。`threshold_mps` 是有符号米制分量阈值，`sigma_multiplier` 默认 2，可为 0。“载入当前会话配置示例”使用当前普通测量的会话，生成正向、反向和横向三个方向，仍需显式计算。配置原文直接交核心，浏览器不预解析数值、删除未知字段或改写重复键。

每一证据行显示目标／片段、方向 ID、方向分量、沿同方向协方差得到的标准差、闭区间和阈值：

- `lower_mps > threshold_mps`：确定高于阈值。
- `upper_mps <= threshold_mps`：确定不高于阈值。
- 其余：阈值关系未确认。

这描述当前米制滤波模型的速度分量。区间不是概率置信区间，也不是欧氏速率范围，不表示真实车辆速度或持续超限。不能用当前表中最差方向的速度标准差替代指定方向标准差。k 为 0 时仍验证并报告真实协方差标准差；数值超出核心支持范围时整批报错，不静默收缩区间。

只有 Ready 目标产生证据。初始化、不确定性超限、异常观测、数值不可用和投影拒绝进入不可判定表；缺测帧不补零，不回读隐藏预测。每一帧独立求值，核心没有时间水位、累计事件或恢复状态。

实际普通源或方向配置变化使结果失效；同原文重算的原始测量帧完全相同时可继续使用旧证据，测量载荷变化则需重算。新的配置、示例和上游计算会取消旧准备；失败的证据计算不修改普通测量结果。表内显示六位有效数字，行悬停显示核心原值，下载保留完整数值。

本入口只消费普通测量，不隐式选择健康门控或其他联合结果。Web 输入与输出各限制 8 MiB；核心另限制配置 1 Mi 字符、单帧 1 Mi 字符和批次 5000 帧。需要更长数据流时使用原生 `--velocity-evidence`。

## 与已查生态能力的关系

本批有界核对了 [Moon-Kalman 0.2.1](https://mooncakes.io/docs/Lyllyl789/moon-kalman@0.2.1)、[MBMOT 0.3.1 analytics](https://mooncakes.io/docs/python123-ops/mbmot@0.3.1/analytics) 和 [moonbitSPC 0.2.0](https://mooncakes.io/docs/mwqcodex/moonbitSPC@0.2.0) 官方 API。Moon-Kalman 已有速度限值检查、标量 ConfidenceBand 和滑窗；MBMOT 已有逐帧原子空间事件；moonbitSPC 已有多窗比较、均值和汇总合并。

所查 API 未见直接消费 MoonGround 当前已接受米制速度及完整二维协方差、沿显式方向给出三态阈值证据并遵守既有质量状态的接口。方向投影、标量区间和普通阈值判断已有通用数学基础；本功能的区别是这些基础与现有米制测量契约的具体结合。该结论限于已查版本和页面。
