# 显式圆盘足迹的区域证据

普通“本帧测量”下方的区域折叠区同时保留原点位置证据和独立的圆盘足迹证据。先完成普通测量，填写原区域配置，再在“显式圆盘足迹”中填写：

```json
{ "radius_m": 0.25 }
```

点击“计算圆盘足迹区域证据”，以当前 Ready 米制模型锚点为圆心、半径 0.25 m 计算。半径必须有限且非负，0 合法；同次计算所有目标共用该半径。需要不同尺寸时由调用者分别计算。半径由调用者明确提供，浏览器和核心都不从像素框、类别或速度方向估计物理尺寸。

原区域配置沿用 [点位置区域入口](zones-web.md) 的会话、严格凸顶点、k 和容量规则。Web 将两份原文字符串封装为新 source，不先解析或改写其数字：

```json
{
  "position": "{\"session_id\":\"warehouse-example\",\"zones\":[{\"zone_id\":\"work-area\",\"vertices_m\":[[0,0],[4,0],[4,4],[0,4]]}]}",
  "disk": "{\"radius_m\":0.25}"
}
```

该 source 交给纯函数 `moonground_disk_zone_evidence`，请求为 `{source: rawSource, measurements: rawMeasurementNDJSON}`；返回 `{frames}`，没有新观测流、检查点或句柄。命令行使用 `--disk-zone-evidence`。整批下载文件 `moonground-disk-zone-evidence.json` 的帧 kind 为 `disk_zone_evidence_frame`，范围为 `model_position_halfplane_bands_plus_explicit_disk`。

## 读懂位置区间与圆盘区间

核心先按原点位置入口计算每条边的有符号距离 d、外法向标准差 σ 和位置区间，再加入显式圆盘半径 r。r 大于 0 时，合成区间为 `[d − (kσ + r), d + (kσ + r)]`。表格分列原位置区间 `position_lower_m / position_upper_m` 和含圆盘区间 `lower_m / upper_m`；摘要另列半径和 k。半径不会写入协方差，也不改变原位置 σ。

- 所有边的合成上界 ≤ 0：确认在区域内，包含闭边界接触。
- 至少一条边的合成下界 > 0：确认在区域外，并返回首条原边编号。
- 其余：区域关系未确认。外侧接触的下界为 0 时，不满足在外的严格分离条件。

半径为 0 时，原位置上下界、合成上下界、三态和分离边与点位置入口逐值一致。k 为 0 仍保留非零圆盘，仍校验并报告真实 SPD 协方差的法向标准差。若正数贡献在相加时丢失、合成端点未严格扩展或出现溢出，核心报数值错误；较大物体不会掩盖原位置区间的数值错误。

判定针对当前模型位置支持范围与调用者声明的圆盘。区间不是概率置信区间，不包含朝向或形状不确定性，也不认证观测到的真实目标轮廓。确认在外依赖边法向的充分分离；角点附近即使几何上不相交，也可能仍未确认。未确认不能解释为相交。

摘要跟随原普通测量滑块。选择当前目标与区域后，只展开该行各边；折叠时不创建各边表。六位有效数字用于阅读，行悬停和下载保留核心原值。浏览器只排版核心输出，不计算几何或协方差。

## 输入变化和不可判定状态

修改圆盘选项只清除圆盘结果，保留点位置结果；修改共享区域配置会清除两类区域结果。原普通输入实际编辑使两类结果失效。同原文重算且测量原始全文相同可继续使用旧结果，测量载荷变化则须重新计算。速度、过线、健康门控输入与该入口独立。

准备期间的新编辑、示例或普通测量重算取消旧请求，迟到结果不能覆盖新状态。相同有效输入下计算失败保留已显示结果；原普通测量不会被下游错误覆盖。初始化、不确定性超限、异常观测、数值不可用和投影拒绝沿用原不可判定原因；缺测不补零，不读取隐藏预测。

Web 输入与输出各限 8 MiB；核心 source wrapper、两份内部文档和单帧各限 1 Mi UTF16 单元，原始测量总计 8 Mi、最多 5000 帧。原区域的 `max_tracks × 全部区域边数 ≤ 65536` 工作量限制保持不变。

## 与本批查验的生态能力的关系

本批做了 3 次有界官方检索，查看 3 个候选的详情或源码：

- [moon_rapier 官方页](https://mooncakes.io/docs/Milky2018/moon_rapier) 当前列出 0.5.1，提供 2D/3D 物理碰撞和查询。[所查官方 0.3.0 源码](https://mooncakes.io/assets/Milky2018/moon_rapier%400.3.0/collision/narrow_phase3d.mbt.html) 已有凸形 Minkowski 支持与 GJK，支持函数本身已有生态实现。
- [mooncollider 0.2.1 官方源码](https://assets.mooncakes.io/assets/uiwcvb/mooncollider%400.2.1/narrowphase.mbt.html) 有多边形双侧 SAT 和圆与多边形碰撞；所查文件的输入为几何形状，没有位置协方差参数。
- [moonslicer 0.1.2 官方 API](https://mooncakes.io/docs/chgttyyr/moonslicer) 有多边形包含、相交、距离与内外偏置，服务打印轮廓和间隙分析。

本功能的增量是当前已接受米制测量契约下，将显式固定圆盘与完整位置协方差分开保留，输出逐边位置区间、合成区间和保守三态。上述所查页面未见这一直接接口；结论限于这些版本和页面，不将通用碰撞、偏置或 Minkowski 运算作为新增能力。
