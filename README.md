# MoonGround

固定相机目标轨迹的米制地面测量库，提供镜头校正、严格与稳健标定、像素坐标变换、协方差投影、真实时间运动估计、轨迹分段、双向过线、法向协方差侧别证据及其原子健康门控分析、区间通行时间、确认时刻分窗与普通／健康门控原始观测的共同恢复，指定地面方向的速度协方差证据、米制凸区域的位置协方差关系及显式圆盘／非对称凸足迹、逐帧逐目标形状绑定及同形状区域证据确认序列，以及保留累计的显式标定切换。

完整说明、随测试执行的 MoonBit 示例、CLI 协议与复现命令见 [README.mbt.md](README.mbt.md)。该文件是文档源文件。当前开发版本为 `0.26.0`，尚未发布到 Mooncakes。
