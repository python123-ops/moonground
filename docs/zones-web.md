# 米制凸区域的位置证据

普通“本帧测量”下方的凸区域折叠区消费已经计算的普通测量帧，独立于相邻速度证据。填写米制区域配置，点击“计算凸区域位置证据”，结果跟随原普通测量滑块；整批下载保存全部帧，kind 为 `zone_evidence_frame`，范围为 `model_position_halfplane_bands`。没有新观测流、事件计数或检查点。

```json
{
  "session_id": "warehouse-example",
  "zones": [
    {
      "zone_id": "work-area",
      "vertices_m": [
        [0, 0],
        [4, 0],
        [4, 4],
        [0, 4]
      ],
      "sigma_multiplier": 2
    }
  ],
  "max_tracks": 1000
}
```

区域由 3—32 个按边顺序排列的米制顶点定义，必须简单且严格凸。顺时针或逆时针均可；核心保留原顶点及边顺序，边编号从 0 开始。重复点、共线边、凹多边形、星形和超出几何数值支持范围的输入报错。`sigma_multiplier` 默认 2，可为 0。区域配置与标定的像素 ROI、过线门和健康地标分别独立，不隐式转换坐标或接管它们的配置。

核心按每条边的外法向计算当前位置的有符号支持线距离、同方向协方差标准差和闭区间：

- 所有边的上界 ≤ 0：确认在区域内，包含闭边界。
- 至少一条边的下界 > 0：确认在区域外，并返回首条分离边编号。
- 其余：区域关系未确认。

确认在外依赖某个边法向的充分分离证据。角点附近即使椭圆与区域实际不相交，也可能缺少单条边的分离证据而未确认。因此未确认不能解释为已相交。这是当前模型位置的确定性支持区间，不是概率置信区间，也不表示目标物理轮廓或完整椭圆与多边形相交判定。

摘要表每个目标、区域显示一行三态证据。下方选择当前目标与区域，只展开该行的边距离、外法向、法向标准差和上下界。浏览器直接格式化核心输出，不重算几何、协方差或判定；六位有效数字用于表格阅读，悬停行和整批下载保留核心原值。k 为 0 仍验证并报告真实 SPD 协方差的方向标准差，数值不受支持时整批报错。

只有当前 Ready 位置生成证据。初始化、不确定性超限、异常观测、数值不可用与投影拒绝进入不可判定表；缺测不补零，也不读取隐藏预测。该入口不产生区域进入、离开、占用或停留事件。

普通源或区域配置实际编辑使区域证据失效。同原文重算且原始测量全文相同可继续使用旧结果，载荷改变则需显式重算。速度配置、过线和健康门控输入不影响区域结果；区域配置也不清除它们。迟到准备不能覆盖新配置、示例或上游计算。证据失败保留原普通测量。

每个配置允许 1—16 个区域、最多 10000 个目标；`max_tracks × 所有区域的边数之和 ≤ 65536`，核心在计算前校验工作量。Web 输入、输出各限 8 MiB，核心配置与单帧各限 1 Mi UTF16 单元、批次最多 5000 帧。原生命令为 `--zone-evidence`。

## 与已查生态能力的关系

本批有界核对了 [MBMOT 0.3.1 analytics](https://mooncakes.io/docs/python123-ops/mbmot@0.3.1/analytics) 和 [Moon-Kalman 0.2.1](https://mooncakes.io/docs/Lyllyl789/moon-kalman@0.2.1) 官方 API。MBMOT 已有 PolygonRegion、区域进入／离开、占用及按帧停留；其所查 TrackSample 接口使用身份、分类和 bbox。Moon-Kalman 已有位置边界、协方差检查、SafetyEnvelope 和标量 ConfidenceBand。

所查页面未见直接消费当前已接受米制位置及完整二维协方差、输出任意严格凸区域逐边支持区间和 Inside／Outside／Indeterminate 的接口。本功能区别在该测量契约和保守分离证据，不把区域事件、通用几何或标量区间本身作为新增能力；结论限于已查版本及页面。
