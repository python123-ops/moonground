# 固定凸足迹的区域证据

普通“本帧测量”下方的区域折叠区，在原点位置证据之后提供“物理足迹显示”选择。默认圆盘模式保留 [原圆盘入口](disk-zones-web.md) 的配置、按钮、下载和结果；选择凸足迹模式后，填写相对当前米制模型锚点的固定顶点偏移：

```json
{
  "vertices_offset_m": [
    [-0.25, -0.25],
    [1, -0.25],
    [1, 0.25],
    [-0.25, 0.25]
  ]
}
```

这个已知形状沿 ground +x 方向比 −x 方向长。核心以原锚点平移形状，不按顶点质心重新定中心，不从速度或像素框推断朝向。顶点已在米制 ground 坐标轴中定向；输入不包含朝向、形状或尺寸不确定性。同次计算所有目标共用这一显式形状，需要不同形状时由调用者分组计算。

足迹须由 3—32 个有限顶点按边顺序构成简单严格凸多边形，顺时针或逆时针均可，保留输入顺序。原点必须在闭足迹内，可以位于边或顶点上；不接受点、线段、全零、重复点、共线、凹形、自交或原点在外的形状。不会自动取凸包修补输入。原区域配置沿用 [点位置区域入口](zones-web.md)，仍与标定像素 ROI、速度证据和过线定义分别独立。

点击“计算凸足迹区域证据”后，结果跟随原普通测量滑块。模式切换只改变显示，不自动计算、不取消另一种足迹的准备，也不丢弃已完成结果。两种足迹的配置、计算和下载分别保存；点位置证据始终保持原独立入口，没有新观测流、事件或检查点。

## 三列区间的含义

核心先计算当前 Ready 位置及完整二维协方差的原位置支持区间。对每条区域边，再投影固定足迹的所有顶点，分别取得带符号物理支持的最小值和最大值。该支持使用原边几何的距离计算；核心不以舍入后的法向点积代替。非对称形状的两侧支持不同，不能取最大绝对值变成一个圆盘半径。

选中目标与区域后，各边表分列：

- `position_lower_m / position_upper_m`：未加入形状的原位置区间。
- `footprint_lower_m / footprint_upper_m`：相对锚点的带符号物理支持，包含零。
- `lower_m / upper_m`：组合位置协方差范围与显式形状的合成区间。

原位置的法向标准差、距离和上下界保持不变。某侧物理支持恰为零时，该侧合成端点直接保留原位置端点；因此锚点在足迹边或顶点上是合法情况。正的尺寸贡献或位置贡献在浮点相加时被吞掉、端点无法扩展或出现溢出时，核心报数值错误；形状不能掩盖原位置区间的数值错误。

所有合成上界 ≤ 0 时确认在区域内，包含闭边界接触。任一合成下界 > 0 时确认在区域外，并返回首条分离边编号。其余为区域关系未确认。分离证据限于区域边法向；角点附近即使几何上不相交也可能未确认，未确认不能解释为相交。这是模型位置支持范围与声明形状的确定性判定，区间不是概率置信区间，也不认证实际观测目标的物理轮廓。

摘要显示足迹顶点数、k、三态和分离边。只展开当前所选目标与区域的各边，隐藏或折叠时不生成其明细表。六位有效数字用于阅读，行悬停和整批下载保留核心原值。浏览器只格式化核心输出，不进行支持函数、几何或协方差运算。

## 原文协议和有效性

Web 将共享区域配置与凸足迹选项分别作为原文字符串交给核心，保留数字 token、重复字段和严格类型校验：

```json
{
  "position": "{\"session_id\":\"warehouse-example\",\"zones\":[{\"zone_id\":\"work-area\",\"vertices_m\":[[0,0],[4,0],[4,4],[0,4]]}]}",
  "footprint": "{\"vertices_offset_m\":[[-0.25,-0.25],[1,-0.25],[1,0.25],[-0.25,0.25]]}"
}
```

纯函数 `moonground_footprint_zone_evidence` 接收 `{source: rawSource, measurements: rawMeasurementNDJSON}`，返回 `{frames}`。帧 kind 为 `footprint_zone_evidence_frame`，scope 为 `model_position_halfplane_bands_plus_explicit_convex_footprint`。整批下载为 `moonground-footprint-zone-evidence.json`，命令行入口为 `--footprint-zone-evidence`。旧点、圆盘协议不接受这些新选项，也不做隐式转换。

修改凸足迹选项只清除凸足迹结果；修改圆盘选项只清除圆盘结果。共享区域配置或普通原始输入实际变化会使相应点、圆盘和凸足迹结果失效。同原文重算且测量载荷全文相同可继续使用旧结果，载荷变化需显式重算。速度、门和健康门控输入不影响这里的结果。

迟到准备不能覆盖新编辑、示例或上游计算；同一有效输入下计算失败保留已经显示的结果。初始化、不确定性超限、异常观测、数值不可用与投影拒绝沿用原不可判定原因，缺测不补零，不读隐藏预测。原普通测量不会被下游错误覆盖。

输入和输出各限 8 MiB UTF8；核心 wrapper、各内部文档和单帧各限 1 Mi UTF16 单元，内部 JSON 转义也计入 wrapper 限额。原始测量总计 8 Mi UTF16 单元、最多 5000 帧；外层纯函数请求上限 16 Mi。原 `max_tracks × 全部区域边数 ≤ 65536` 限制保持不变。核心每帧先按区域边和形状计算一次支持，再复用于当前可判定目标，不按目标重复投影形状。

## 本批官方生态核查

本批限定 3 次官方站点检索和 3 个候选详情页：

- [mooncollider 0.2.1](https://mooncakes.io/docs/uiwcvb/mooncollider@0.2.1) 已有 `Shape::support`、凸包与有序凸顶点构造、SAT、GJK/EPA。凸支持和普通形状碰撞已有公开实现。
- [moon_rapier 0.5.2 collision](https://mooncakes.io/docs/Milky2018/moon_rapier@0.5.2/collision) 已有 `ColliderBuilder::convex_hull / convex_polyline`，以及三维凸形和凸分解接口。
- [moonslicer 0.1.2](https://mooncakes.io/docs/chgttyyr/moonslicer@0.1.2) 已有多边形包含、相交、距离与内外偏置；所查偏置接口服务打印轮廓，使用角平分线和 miter 限制。

这三个所查 API 页未检索到 covariance 字段或直接接收当前 Ready 米制位置与完整二维协方差、组合锚点相对非对称足迹并输出逐边保守三态的接口。这里的增量是该测量契约与分开保留的位置、物理形状和合成证据；不把通用凸支持、凸包或碰撞算法作为新增能力。结论限于所查版本和页面。
